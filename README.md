# ChiriHome

Aplicación Android para conectarse a un servidor doméstico local y centralizar el acceso a una biblioteca personal de contenido multimedia.

## Objetivo

ChiriHome busca ofrecer una experiencia sencilla para:

- Explorar y organizar música alojada en un servidor local.
- Reproducir música desde el dispositivo Android y, conforme avance el desarrollo, integrar reproducción en otros equipos compatibles.
- Explorar una biblioteca personal de vídeos y películas.
- Conectarse de forma segura a los servicios del servidor doméstico.

La disponibilidad de cada función depende de su implementación y validación. Este repositorio documentará su evolución.

## Principios de desarrollo

1. Avanzar en incrementos pequeños y verificables.
2. Documentar las decisiones técnicas relevantes.
3. Priorizar la seguridad de la conexión entre Android y el servidor.
4. No dar por terminada una función hasta haberla probado.
5. Mantener diferenciadas las funciones implementadas, en desarrollo y planificadas.
