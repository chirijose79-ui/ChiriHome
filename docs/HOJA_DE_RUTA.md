# Hoja de ruta inicial

Esta hoja de ruta es una propuesta de trabajo. Los elementos no se consideran terminados hasta que se implementen y se verifiquen.

## Fase 1: Preparación

- [x] Crear el repositorio independiente ChiriHome.
- [x] Añadir la descripción inicial del proyecto.
- [x] Documentar la arquitectura conceptual y la hoja de ruta.
- [ ] Revisar el estado del repositorio original y decidir qué código se trasladará.
- [ ] Incorporar el código de la aplicación sin exponer secretos ni archivos locales innecesarios.

## Fase 2: Base Android

- [ ] Confirmar módulos, estructura y versiones de herramientas.
- [ ] Verificar que el proyecto compile desde un entorno limpio.
- [ ] Documentar cómo ejecutar las pruebas y generar una compilación de desarrollo.

## Fase 3: Conexión al servidor

- [ ] Documentar la configuración de la dirección del servidor.
- [ ] Verificar conectividad y manejo de errores.
- [ ] Verificar autenticación y almacenamiento seguro de la sesión, si corresponde.

## Fase 4: Experiencia multimedia

- [ ] Verificar la consulta y exploración de la biblioteca musical.
- [ ] Verificar la reproducción de música en el dispositivo.
- [ ] Documentar y probar la integración con reproductores o protocolos adicionales.
- [ ] Evaluar la exploración y reproducción de vídeos y películas.

## Fase 5: Calidad y publicación

- [ ] Añadir pruebas para los flujos principales.
- [ ] Documentar requisitos de seguridad y configuración.
- [ ] Preparar el procedimiento de instalación y actualización.

## Criterio para cerrar una tarea

Una tarea se marca como terminada cuando el cambio está implementado, las comprobaciones pertinentes pasan y la documentación refleja el comportamiento real.
